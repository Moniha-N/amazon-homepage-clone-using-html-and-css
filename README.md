# amazon-homepage-clone-using-html-and-css

A frontend Amazon-inspired homepage clone built using HTML and CSS.

## Features
- Responsive Navbar
- Search Bar
- Product Grid Layout
- Personalized Recommendation Section
- Hover Effects
- Back To Top Footer

## Technologies Used
- HTML5
- CSS3
- Font Awesome

## What I Learned
- Flexbox
- CSS Grid
- Hover Effects
- Alignment & Spacing
- Structuring Web Layouts
- Git & GitHub Basics
